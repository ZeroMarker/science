# 氨基酸基础知识与速查

[返回文档导航](../README.md)

本文面向生物化学入门，整理常见 20 种蛋白质氨基酸的结构、名称、缩写、侧链性质及营养分类，并说明它们如何形成肽链和参与蛋白质结构。

## 一、基本结构

常见蛋白质氨基酸属于 α-氨基酸：氨基和羧基连接在同一个 α-碳（Cα）上，其余两个连接位置通常为氢和侧链 R。

一般结构可简写为：

```text
      H
      |
H₂N — Cα — COOH
      |
      R
```

这是未解离形式的通式。在接近中性 pH 的水溶液中，游离氨基酸的 α-氨基通常为 `—NH₃⁺`，α-羧基通常为 `—COO⁻`。脯氨酸的侧链回接到氨基氮上，需作为环状结构理解。

- **共同骨架：** 构成肽链的重复部分。
- **侧链 R：** 决定大小、极性、电荷及反应性等差异。
- **手性：** 常见 20 种中，甘氨酸因 R 为氢而无手性；核糖体合成蛋白质时通常使用其余氨基酸的 L 型。
- **残基：** 氨基酸进入肽链后的结构单元称为氨基酸残基。

参考：[EMBL-EBI：氨基酸的基本结构与手性](https://www.ebi.ac.uk/training/online/courses/foundations-protein-structure/fundamentals-of-protein-composition/the-building-blocks-amino-acids/)。

## 三、按侧链性质理解

| 分类角度 | 代表氨基酸 | 主要特点 |
| --- | --- | --- |
| 非极性脂肪族及相关侧链 | G、A、V、L、I、M、P | 多数偏疏水；G、P 对主链构象有特殊影响 |
| 芳香族侧链 | F、Y、W | 含芳香环；Y、W 同时含有极性基团 |
| 极性、通常不带电侧链 | S、T、N、Q、C | 可参与氢键或其他极性相互作用；C 还具有巯基反应性 |
| 酸性侧链 | D、E | 接近生理 pH 时通常带负电 |
| 碱性侧链 | K、R、H | K、R 通常带正电；H 的质子化对局部环境较敏感 |

这些分类并非完全互斥。例如，酪氨酸既是芳香族氨基酸，也有可形成氢键的羟基。组氨酸归入碱性氨基酸，不表示其侧链在生理 pH 下始终带正电。

结构理解时可优先记住：

- **Gly：** 小而灵活，可出现在其他残基难以采用的紧密转角构象中。
- **Pro：** 环状侧链限制主链转动，常与转角或螺旋弯折有关。
- **Cys：** 两个半胱氨酸残基的巯基可在适当氧化条件下形成二硫键。
- **Ser、Thr、Tyr：** 含羟基，是常见的蛋白质磷酸化位点类型。
- **Val、Leu、Ile：** 统称支链氨基酸（BCAA）。

参考：[EMBL-EBI：侧链化学性质](https://www.ebi.ac.uk/training/online/courses/foundations-protein-structure/fundamentals-of-protein-composition/the-building-blocks-amino-acids/general-structure/)。

## 四、酸碱性、pKa 与等电点

- **pKa：** 表示某个可解离基团的酸碱平衡特征。对该基团而言，pH 等于 pKa 时，质子化和去质子化形式的浓度相等。
- **pH 低于 pKa：** 该基团更倾向保留质子。
- **pH 高于 pKa：** 该基团更倾向失去质子。
- **等电点 pI：** 分子平均净电荷为零时的 pH；不代表分子内部没有正、负电荷。

判断游离氨基酸的净电荷，需要同时考虑 α-氨基、α-羧基及可电离侧链。进入肽链后，内部残基的 α-氨基和 α-羧基参与形成肽键，不能继续按游离氨基酸逐个计算；应考虑链端和可电离侧链。

同一基团的 pKa 会受溶剂和蛋白质局部环境影响，精确分析时需说明条件。参考：[EMBL-EBI：电离与 pKa](https://www.ebi.ac.uk/training/online/courses/foundations-protein-structure/fundamentals-of-protein-composition/the-building-blocks-amino-acids/ionisation-and-pka-values/)。

## 六、从氨基酸到肽链

肽键是连接氨基酸残基的酰胺键，常见连接单元为 `—C(=O)—NH—`。涉及脯氨酸残基时，酰胺氮上没有氢。

```text
N 端 → 残基 1 — 残基 2 — 残基 3 → C 端

示例：Ala–Gly–Ser
单字母：AGS
```

序列通常从 **N 端写到 C 端**。肽键具有部分双键性质，使肽单元大致保持平面；主链构象还依赖相邻单键的二面角。

教材常以“脱水缩合”概括肽键形成的净变化，但细胞中的肽链合成需要活化的氨基酸和核糖体等体系，不能理解为游离氨基酸在水中自行连接。

参考：[EMBL-EBI：肽键性质](https://www.ebi.ac.uk/training/online/courses/foundations-protein-structure/fundamentals-of-protein-composition/the-peptide-bond-and-primary-structure/the-nature-of-the-peptide-bond/) · [IUPAC/IUBMB：序列书写方向](https://iupac.qmul.ac.uk/AminoAcid/A2021.html)。

## 七、与蛋白质结构的关系

| 结构层次 | 主要内容 |
| --- | --- |
| 一级结构 | 氨基酸残基在链中的排列顺序 |
| 二级结构 | α-螺旋、β-折叠等局部主链结构 |
| 三级结构 | 单条多肽链的整体三维组织 |
| 四级结构 | 多条多肽链之间的组装关系，并非所有蛋白质都有 |

蛋白质结构由多种作用共同影响：疏水效应促使非极性基团在适当环境中聚集；氢键、静电作用及范德华相互作用参与稳定结构；部分蛋白质还有二硫键。残基的实际作用取决于所在位置和周围环境，不能只按一个侧链标签判断。

参考：[EMBL-EBI：蛋白质结构课程](https://www.ebi.ac.uk/training/online/courses/foundations-protein-structure/) · [结构稳定作用](https://www.ebi.ac.uk/training/online/courses/foundations-protein-structure/principles-of-protein-folding-and-architecture/tertiary-structure/stabilisation-forces/)。

## 八、常见混淆

| 容易混淆的概念 | 区别 |
| --- | --- |
| Asp / Asn | 天冬氨酸与天冬酰胺；侧链分别为羧酸/羧酸根和酰胺 |
| Glu / Gln | 谷氨酸与谷氨酰胺；侧链分别为羧酸/羧酸根和酰胺 |
| Met / Cys | 都含硫；常见二硫键由 Cys 形成 |
| L/D 与单字母代码 | L/D 表示构型；序列中的 L 表示 Leu，D 表示 Asp |
| X 与终止符 | X 常表示未知或未指定氨基酸；许多序列格式用 `*` 表示翻译终止，需查看格式约定 |
| 20 种与所有氨基酸 | 常见 20 种不是全部；序列代码还包括 Sec（U，硒代半胱氨酸）和 Pyl（O，吡咯赖氨酸） |

代码说明参考：[DDBJ 序列代码规范](https://www.ddbj.nig.ac.jp/ddbj/code-e.html)。

## 九、可视化学习路径

1. **看单个分子：** 在 MolView 或 PubChem 检索 `glycine`、`L-alanine`、`L-proline`，对照骨架和侧链。
2. **看手性：** 比较 L-alanine 与 D-alanine 的三维排列。
3. **看肽链：** 从 RCSB PDB 选择蛋白质结构，在 Mol* 或 iCn3D 中查看主链、残基侧链和二硫键。
4. **结合性质解释：** 观察疏水残基、带电残基在所选蛋白质中的位置，并留意膜蛋白等环境差异。
