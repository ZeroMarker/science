# 维生素基础知识与速查

[返回文档导航](../README.md)

本文整理人体所需的 13 种维生素，介绍分类、主要作用、常见食物来源及缺乏和过量的风险，供基础学习与查阅。具体补充需求取决于年龄、生理状态、饮食、吸收能力和用药情况，本文不提供个人诊断或补充剂处方。

## 一、维生素是什么

维生素是人体维持正常生长、细胞功能及代谢所需的一类有机微量营养素。它们参与机体功能，但不像碳水化合物、脂肪和蛋白质那样直接提供热量。“参与能量代谢”不等于“吃了就能额外增加精力”。

通常所说的 13 种包括 **A、C、D、E、K，以及 8 种 B 族维生素**。同一种维生素可能包含多种具有相关生物活性的化合物，并不总是对应单个分子。

参考：[MedlinePlus：维生素概述](https://medlineplus.gov/ency/article/002399.htm)。

## 二、脂溶性与水溶性

| 分类 | 包含种类 | 吸收与储存特点 | 理解重点 |
| --- | --- | --- | --- |
| 脂溶性 | A、D、E、K | 与脂肪吸收有关，可在肝脏、脂肪等组织中储存 | 某些种类过量可蓄积，但不能将四种的风险一概而论 |
| 水溶性 | B1、B2、B3、B5、B6、B7、B9、B12、C | 体内储量及排泄特点各异，多数需规律摄入；B12 可储存较长时间 | 能经尿液排出不代表高剂量安全 |

分类与储存参考：[MedlinePlus 维生素概述](https://medlineplus.gov/ency/article/002399.htm)。水溶性维生素的过量风险可见下文 B6、烟酸和维生素 C 的说明。

## 三、13 种维生素速查

食物来源为示例，不是含量排名，也不表示吃某一种食物即可满足全部需要。强化食品的配方因地区和产品而异，应查看标签。各行名称链接对应 NIH 膳食补充剂办公室（ODS）的官方资料。

| 维生素 | 常见名称或形式 | 分类 | 主要生理作用 | 常见食物来源 |
| --- | --- | --- | --- | --- |
| [A](https://ods.od.nih.gov/factsheets/VitaminA-Consumer/) | 视黄醇等预成型维生素 A；部分类胡萝卜素可转化为 A | 脂溶性 | 视觉、免疫功能、生长与发育 | 肝脏、蛋、乳制品；胡萝卜、深绿叶菜等提供维生素 A 原 |
| [B1](https://ods.od.nih.gov/factsheets/Thiamin-Consumer/) | 硫胺素（Thiamin/Thiamine） | 水溶性 | 能量代谢与正常细胞功能 | 猪肉、全谷物、豆类、强化谷物 |
| [B2](https://ods.od.nih.gov/factsheets/Riboflavin-Consumer/) | 核黄素（Riboflavin） | 水溶性 | 能量代谢及细胞生长、功能 | 奶、蛋、肉类、蘑菇、强化谷物 |
| [B3](https://ods.od.nih.gov/factsheets/Niacin-Consumer/) | 烟酸、烟酰胺，统称 Niacin | 水溶性 | 能量代谢与细胞功能 | 禽肉、鱼、肉类、花生、全谷物或强化谷物 |
| [B5](https://ods.od.nih.gov/factsheets/PantothenicAcid-Consumer/) | 泛酸（Pantothenic acid） | 水溶性 | 营养物质代谢，尤其脂肪的合成与分解 | 肉、蛋、全谷物、蘑菇等，分布较广 |
| [B6](https://ods.od.nih.gov/factsheets/VitaminB6-Consumer/) | 吡哆醇等多种形式 | 水溶性 | 多种酶反应、脑发育与免疫功能 | 鱼、禽肉、薯类、部分水果 |
| [B7](https://ods.od.nih.gov/factsheets/Biotin-Consumer/) | 生物素（Biotin） | 水溶性 | 脂肪、糖和氨基酸代谢 | 熟蛋、鱼、肉类、坚果和种子 |
| [B9](https://ods.od.nih.gov/factsheets/folate-consumer/) | 叶酸类（Folate）；补充剂常见 Folic acid | 水溶性 | DNA 合成、细胞分裂；胎儿早期发育 | 深绿叶菜、豆类、柑橘；部分强化谷物 |
| [B12](https://ods.od.nih.gov/factsheets/VitaminB12-HealthProfessional/) | 钴胺素类，如氰钴胺、甲钴胺 | 水溶性 | 神经系统功能、红细胞形成与 DNA 合成 | 鱼、肉、蛋、乳制品，以及添加 B12 的强化食品 |
| [C](https://ods.od.nih.gov/factsheets/VitaminC-Consumer/) | 抗坏血酸（Ascorbic acid） | 水溶性 | 胶原形成、抗氧化，促进非血红素铁吸收 | 柑橘、猕猴桃、甜椒、西兰花等蔬果 |
| [D](https://ods.od.nih.gov/factsheets/VitaminD-HealthProfessional/) | D2（麦角钙化醇）、D3（胆钙化醇） | 脂溶性 | 钙磷代谢与骨骼矿化等 | 富脂鱼类、蛋黄、部分强化食品；皮肤也可合成 |
| [E](https://ods.od.nih.gov/factsheets/VitaminE-Consumer/) | 生育酚等；人体营养需要以 α-生育酚为核心 | 脂溶性 | 抗氧化，参与免疫等功能 | 植物油、坚果、种子 |
| [K](https://ods.od.nih.gov/factsheets/VitaminK-Consumer/) | K1（叶绿醌）、K2（甲萘醌类） | 脂溶性 | 正常凝血及骨相关蛋白的功能 | 绿叶蔬菜、部分植物油；纳豆等发酵食品 |

## 四、缺乏时可能出现什么

下表概括典型表现，不适合用于自我诊断。同一种表现可能由多种疾病或营养问题引起，缺乏也可能在明显症状出现前已经存在。来源为上表对应的官方资料。

| 维生素 | 典型缺乏表现或影响 |
| --- | --- |
| A | 暗处视力下降、夜盲，严重时损害眼部组织 |
| B1 | 脚气病，可影响神经和心血管系统；严重缺乏也与 Wernicke–Korsakoff 综合征有关 |
| B2 | 口角裂、嘴唇或口腔黏膜改变等 |
| B3 | 严重时出现糙皮病，可涉及皮肤、消化和神经系统 |
| B5 | 单独缺乏罕见；严重缺乏可出现手足麻木、灼痛等 |
| B6 | 贫血、皮炎、口角或舌部改变等 |
| B7 | 缺乏罕见，可出现脱发、皮疹及神经症状 |
| B9 | 巨幼细胞性贫血；孕期不足与胎儿神经管缺陷风险有关 |
| B12 | 巨幼细胞性贫血、手足麻木等神经损害；神经问题可在没有贫血时出现 |
| C | 严重时导致坏血病，包括牙龈出血、瘀斑、伤口愈合不良等 |
| D | 儿童可出现佝偻病，成人可出现骨软化症 |
| E | 缺乏少见，可出现神经、肌肉及视觉问题，常与吸收障碍有关 |
| K | 严重时出现异常出血或凝血问题 |

**词义提示：** 维生素 B1 缺乏导致的“脚气病”与俗称“脚气”的足癣不同，后者是真菌感染。

## 五、过量与相互作用

| 项目 | 主要注意点 | 来源 |
| --- | --- | --- |
| 预成型维生素 A | 高摄入可能中毒；妊娠期过量可导致胎儿出生缺陷 | [ODS：A](https://ods.od.nih.gov/factsheets/VitaminA-Consumer/) |
| β-胡萝卜素补充剂 | 与预成型 A 的风险不同；吸烟或曾吸烟者使用高剂量补充剂，肺癌风险可能增加 | [ODS：A](https://ods.od.nih.gov/factsheets/VitaminA-Consumer/) |
| D | 过量补充可造成高钙血症，严重时损伤肾脏等器官 | [ODS：D](https://ods.od.nih.gov/factsheets/VitaminD-HealthProfessional/) |
| E | 高剂量补充可能增加出血风险，尤其需要考虑抗凝或抗血小板药物 | [ODS：E](https://ods.od.nih.gov/factsheets/VitaminE-Consumer/) |
| K | 与华法林存在重要相互作用；通常强调保持摄入稳定，避免自行突然增减 | [ODS：K](https://ods.od.nih.gov/factsheets/VitaminK-Consumer/) |
| B6 | 长期高剂量补充可能导致周围神经损害 | [ODS：B6](https://ods.od.nih.gov/factsheets/VitaminB6-Consumer/) |
| B3 | 较高剂量烟酸可引起潮红；药理剂量还可能造成肝损伤等，形式与剂量影响风险 | [ODS：烟酸](https://ods.od.nih.gov/factsheets/Niacin-Consumer/) |
| B9 补充剂 | 大量摄入可能纠正 B12 缺乏导致的贫血，却不能防止其神经损害，从而掩盖问题 | [ODS：叶酸](https://ods.od.nih.gov/factsheets/folate-consumer/) |
| C | 高剂量可导致腹泻、恶心和腹部痉挛等 | [ODS：C](https://ods.od.nih.gov/factsheets/VitaminC-Consumer/) |
| B7 | 补充剂中的较高剂量生物素可干扰部分化验，造成错误结果；检查前应告知医务人员 | [ODS：生物素](https://ods.od.nih.gov/factsheets/Biotin-Consumer/) |

没有列入此表不代表可以无限量摄入。多维片、单方补充剂和强化食品可能同时提供同一种营养素，核对时需合并考虑。

## 六、如何理解摄入量和标签

本文不列一套适用于所有人的每日剂量。查阅数值前，应先确定所用国家或地区的标准、年龄、性别以及妊娠或哺乳等状态。

| 术语 | 含义 | 使用时注意 |
| --- | --- | --- |
| RDA（推荐膳食摄入量） | 满足绝大多数健康个体需要的日均摄入水平 | 不是疾病治疗剂量 |
| AI（适宜摄入量） | 证据不足以制定 RDA 时使用的参考水平 | 不能因名称不同就理解为重要性较低 |
| EAR（平均需要量） | 满足某类健康人群约一半个体需要的水平 | 常用于群体营养评估 |
| UL（可耐受最高摄入量） | 通常不致产生不良健康影响的日摄入上限 | 不是建议达到的目标；有些 UL 只适用于特定形式或来源 |
| DV / NRV 等标签参考值 | 用于营养标签的参考口径 | 不等于针对个人制定的需求量；地区间定义和数值可能不同 |

以上 RDA、AI、EAR、UL 的解释采用美国 DRI 资料口径。参考：[ODS：营养素参考摄入量](https://ods.od.nih.gov/HealthInformation/nutrientrecommendations.aspx)。

单位方面，`1 mg = 1,000 μg`，其中 μg 也常写作 mcg。IU 是与生物活性有关的单位，不同维生素不能共用一个质量换算系数。A 的 RAE、叶酸的 DFE 等当量也不能忽略形式和吸收差异，直接与任意原料质量相比；见 [ODS：A](https://ods.od.nih.gov/factsheets/VitaminA-Consumer/) 和 [ODS：叶酸](https://ods.od.nih.gov/factsheets/folate-consumer/)。

## 七、容易混淆的概念

| 问题 | 正确理解 | 参考 |
| --- | --- | --- |
| B 族是否有 B1 到 B12 共 12 种？ | 目前通常指 8 种：B1、B2、B3、B5、B6、B7、B9、B12，编号不连续 | [MedlinePlus](https://medlineplus.gov/ency/article/002399.htm) |
| Folate 和 Folic acid 完全一样吗？ | Folate 指相关叶酸类化合物；Folic acid 是强化食品和补充剂中常用的形式，生物利用度不同 | [ODS：叶酸](https://ods.od.nih.gov/factsheets/folate-consumer/) |
| 维生素 D 是钙吗？ | D 是维生素，钙是矿物质；D 帮助钙吸收并参与钙磷稳态 | [ODS：D](https://ods.od.nih.gov/factsheets/VitaminD-HealthProfessional/) |
| 水溶性维生素可以随便补吗？ | 不能；B6、烟酸和 C 等在高剂量下也有风险 | 见上文对应资料 |
| B12 来自普通植物性食物吗？ | 天然可靠来源主要为动物性食品；全植物饮食需留意明确添加 B12 的强化食品或适当补充来源 | [ODS：B12](https://ods.od.nih.gov/factsheets/VitaminB12-HealthProfessional/) |
| 有抗氧化功能，就应大量补充吗？ | 生理作用与额外补充的临床收益不同，不能据此推导高剂量能预防疾病 | [ODS：E](https://ods.od.nih.gov/factsheets/VitaminE-Consumer/) |

## 八、建议学习路径

1. 先记住“脂溶性 A、D、E、K；水溶性 B 族和 C”。
2. 用速查表建立“名称—作用—食物来源”的联系。
3. 将缺乏表现与过量风险对照学习，避免把典型症状当作诊断依据。
4. 阅读补充剂标签时，再核对化学形式、每份含量、单位及其他来源的重复摄入。
5. 需要具体摄入量时，从相应官方资料进入，按人群和当地标准查询；存在症状、吸收障碍或用药相互作用时由医生或营养专业人员评估。
