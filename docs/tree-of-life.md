# 生物分类与生命之树工具指南

[返回文档导航](../README.md)

这份指南整理了 9 个用于生命之树探索、分类信息查询和自定义树展示的网站。如果希望像浏览思维导图一样逐步展开、缩放并探索物种之间的关系，可以先体验 OneZoom、LifeMap 和 Ptree。

## 快速选择

| 需求 | 建议优先使用 | 主要用途 |
| --- | --- | --- |
| 缩放探索生命之树，了解物种之间的关系 | OneZoom | 面向公众的交互式生命之树 |
| 像浏览地图一样探索生物类群 | LifeMap | 从大类群逐步深入具体节点 |
| 切换并比较不同来源的分类体系 | Ptree | 汇集多种分类数据源的树状浏览器 |
| 查看综合进化树及其来源 | Open Tree of Life | 综合已发表的系统发育树和分类数据 |
| 查询分类谱系，并关联基因或蛋白质记录 | NCBI Taxonomy | 面向生物序列数据的分类查询 |
| 查询物种及其出现记录、地理分布 | GBIF | 生物多样性开放数据入口 |
| 查询物种接受名、异名和分类目录 | Catalogue of Life | 全球物种名录及来源查询 |
| 查询标准化名称和分类层级 | ITIS | 分类名称、层级及标识信息 |
| 导入自己的树，添加注释并制作图片 | iTOL | 自定义树的展示、注释与导出 |

## 一、交互式生命之树与分类浏览

### 1. OneZoom

**适合：** 初次探索生命之树、课堂演示和了解物种亲缘关系。

- 将大量物种放在同一个可缩放的树形页面中。
- 叶片代表物种，分支展示共同祖先与演化关系。
- 可结合物种图片、名称及导览探索不同类群。
- 核对时官网列出约 223 万个物种；这一数字表示网站当前展示规模，不代表已完整覆盖地球上的所有物种。

入口与来源：[OneZoom 官网](https://www.onezoom.org/)

**本指南建议：** 如果最重视连续缩放、直观浏览和探索体验，可以从 OneZoom 开始。

### 2. Open Tree of Life

**适合：** 探索综合进化关系、追溯来源，以及通过 API 使用树和分类数据。

- 将已发表的系统发育树与分类数据综合为可浏览的生命之树。
- 可浏览综合树和分类体系，并查看相关信息来源。
- 提供数据使用教程和开放 Web API。

入口与来源：[Open Tree of Life 项目主页](https://opentreeoflife.github.io/)

使用提示：综合树同时利用系统发育研究与分类数据，使用具体分支时应查看其来源，避免假定所有分支都有同等程度的研究支持。

### 3. LifeMap

**适合：** 以地图式交互方式逐层探索生命之树。

- 支持缩放、平移并探索不同生物类群。
- 提供类群信息及相关资源链接，可用于教学和研究探索。
- 原文提供的 NCBI 版旧地址，本次访问已跳转到 CNRS 站点。

入口：[LifeMap 当前站点](https://lifemap.cnrs.fr/)

参考：[里昂第一大学项目介绍](https://www.univ-lyon1.fr/en/news/lifemap-exploring-the-tree-of-life)

### 4. Ptree

**适合：** 在一个界面中切换分类数据源，比较不同体系下的物种归属。

- 页面提供 GBIF、Catalogue of Life、ITIS、Open Tree of Life Taxonomy（OTT）、NCBI 等数据源选项。
- 还提供 GTDB、ICTV 等面向特定类群的数据源入口。
- 不同来源各有覆盖范围和分类方法，应结合所选数据源解释树形关系。

入口与来源：[Ptree](https://ptree.org/)

定位说明：Ptree 属于多数据源分类浏览工具；需要导入自己的树文件并进行科研注释时，可优先查看 iTOL。

## 二、专业分类与物种数据库

### 5. NCBI Taxonomy

**适合：** 查询分类节点、谱系及其与核酸和蛋白质数据的关联。

- 可按名称或分类标识符查询生物分类信息。
- 适合与 NCBI 的序列、基因组等数据配合使用。
- Taxonomy Common Tree 可用于查看多个目标类群在 NCBI 分类体系中的共同分类树。

入口：[NCBI Taxonomy](https://www.ncbi.nlm.nih.gov/datasets/taxonomy/) · [Taxonomy Common Tree](https://www.ncbi.nlm.nih.gov/datasets/taxonomy/common-tree/)

**关键区别：** Common Tree 是分类体系的子树，并非输入物种后重新进行序列分析得到的系统发育树。参考：[NCBI 官方解释](https://support.nlm.nih.gov/knowledgebase/article/KA-03471/en-us)。

### 6. GBIF

**适合：** 查询物种信息、出现记录及地理分布数据。

- 汇集来自不同机构的生物多样性数据。
- 可结合物种名称检索和出现记录了解生物的分布情况。
- 用于研究时应检查记录来源、时间和空间信息；地图上的出现记录不等于物种完整的自然分布范围。

入口：[GBIF](https://www.gbif.org/) · [官方项目介绍](https://www.gbif.org/what-is-gbif)

### 7. Catalogue of Life（COL）

**适合：** 查询物种接受名、异名、分类目录及数据来源。

- 提供全球物种名录的检索和浏览入口。
- 提供来源、版本变更、下载及 API 等入口。
- 比较不同资料中的名称时，应同时记录所用目录版本和来源。

入口与来源：[Catalogue of Life](https://www.catalogueoflife.org/)

### 8. ITIS

**适合：** 查询标准化分类名称、分类层级及相关标识信息。

- 提供名称搜索、层级报告和名称比较等工具。
- 提供数据下载与 Web 服务入口。

入口与来源：[Integrated Taxonomic Information System](https://www.itis.gov/)

## 三、自定义树展示与科研制图

### 9. iTOL（Interactive Tree Of Life）

**适合：** 已有树文件，需要调整布局、添加注释并导出图片的用户。

- 可导入 Newick 等树文件，提供常规、圆形及无根等显示方式。
- 支持分支和标签样式、图片及多种数据集注释。
- 提供矢量图和位图导出，适合制作论文或报告中的树图。
- 提供不同访问模式及订阅方案，具体功能范围以官方说明为准。

入口：[iTOL](https://itol.embl.de/) · [文件格式与操作说明](https://itol.embl.de/help.cgi)

使用提示：iTOL 主要负责树的展示和注释；树的推断方法、输入数据和分支支持度需要由上游分析确定。

## 四、分类树与系统发育树的区别

| 类型 | 主要表达内容 | 阅读时需要注意 |
| --- | --- | --- |
| 分类树（Taxonomic tree） | 某个分类体系中的类群归属与层级 | 分类等级不表示固定的演化时间或遗传距离 |
| 系统发育树（Phylogenetic tree） | 根据证据推断的演化关系和共同祖先 | 需要结合数据、方法、支持度及枝长含义理解 |

常见分类等级包括“域 → 界 → 门 → 纲 → 目 → 科 → 属 → 种”，实际体系可能包含额外等级或无等级类群。不能仅凭树的外观判断它属于哪一种，也不能默认枝长代表时间。

不同数据库的名称、物种范围和分类归属可能不同。用于研究时，应记录数据源、版本或访问日期，并结合具体类群的研究文献核对。关于分类层级与系统发育推断的关系，可参考上述 [NCBI 官方解释](https://support.nlm.nih.gov/knowledgebase/article/KA-03471/en-us)。

## 五、建议使用路径

1. **自由探索：** 从 OneZoom 开始，选择熟悉的物种，逐步缩放并观察相关分支。
2. **比较体系：** 在 LifeMap 或 Ptree 中查看目标类群；使用 Ptree 时留意当前数据源。
3. **查询分类与名称：** 按需求使用 NCBI Taxonomy、Catalogue of Life 或 ITIS，并通过 GBIF 补充出现记录。
4. **追溯进化关系：** 使用 Open Tree of Life 查看综合树及相关来源，再查阅具体研究。
5. **制作自己的树图：** 将已有树文件导入 iTOL，添加注释并导出。
